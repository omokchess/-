# 잔향선 (ECHO LINE)

브라우저에서 바로 실행되는 턴제 RPG입니다. `index.html` 파일 하나만 열면 됩니다(설치·서버 불필요, 진행은 브라우저에 자동 저장).

림버스 컴퍼니의 **합(코인 비교) 전투** 방식을 참고해 이름과 세계관, 직업과 보스 기믹을 새로 설계했습니다.

## 전투 규칙
- **합**: 내가 노린 적의 행동이 나를 향하거나, 내 속도가 더 빠르면 합이 됩니다. 기본 위력 + 앞면마다 코인 위력을 비교하고, 진 쪽이 코인을 잃습니다. 한쪽 코인이 바닥날 때까지 반복합니다.
- **정신력**(−45~+45): 앞면 확률 = 50% + 정신력%. −45가 되면 공황에 빠집니다.
- **흐트러짐**: 체력이 문턱 아래로 떨어지면 다음 턴까지 행동 불가, 받는 피해 2배.
- **덱**: S1×3 · S2×2 · S3×1에서 매 턴 2장을 뽑아 고릅니다. 방어(가드·회피·반격)는 언제나 선택할 수 있습니다.
- **공명과 각인**: 같은 감정(분노·환희·비애·공포·집착·공허)의 기술을 함께 쓰면 위력이 오르고 감정 자원이 쌓입니다. 자원은 비장의 기술 「각인」에 씁니다(정신력이 낮으면 폭주할 수 있음).
- **잠재 상태**: 출혈·화상·진동·파열·침잠·호흡(위력·횟수).

## 승객(직업) 10종
| 승객 | 직업 | 고유 기믹 |
| --- | --- | --- |
| 세린 | 혈검사 | 자기 피를 대가로 혈조를 쌓고, 혈조 10으로 불괴 코인 해방 |
| 도윤 | 잿불 사제 | 열기 관리: 재로 바꿔 아군 보호막 / 100을 넘겨 과열 폭딜 |
| 하람 | 종지기 | S1→S2→S3 순서를 이으면 박자 상승, 박자 3의 대종은 전체 진동 폭발 |
| 이브 | 결투사 | 결투 상대 하나와의 합 연승으로 기세를 쌓아 필살 일섬 |
| 무진 | 수호기사 | 도발로 적 공격을 끌어오고, 맞은 만큼 인내를 쌓아 응징 / 수호 맹세 |
| 로아 | 도박사 | 정신력 무시 50% 코인, 뒷면이 행운으로 쌓여 7에서 잭팟 |
| 연 | 심해 시인 | 절망도 행운(50%+|정신력|), 일부러 정신력을 떨어뜨리고 공황 대신 심연 |
| 카이 | 포격수 | 탄약과 충전, 충전이 곧 코인 수가 되는 과충전 포격 |
| 비올라 | 인형술사 | 인형 보호막, 실 4개로 적의 공격을 다른 적에게 돌리는 꼭두각시 춤 |
| 시온 | 시계공 | 고정 속도, 태엽으로 아군 체력을 2턴 전으로 되감기 |

## 잔향체(보스) 12종
시계(자정 카운트다운) · 정육업자(고기 걸이를 먹는 회복) · 사서(수위·배수구·금서 봉인) · 디바(독무대 조명·관객·앙코르) · 가면(매 턴 바뀌는 내성·가면 파괴) · 유령열차(가속·제동·탈선) · 웃는 얼굴(동화: 공황 아군이 적이 됨) · 거인(석화 피부·팔 파괴 시 흐트러짐) · 재봉사(운명 꿰매기: 피해 공유·같은 적 공격 강제) · 쌍둥이 달(낮과 밤·공명·월식 부활) · 거울 속의 차장(내 기술을 그대로 되돌림·조각 반사) · 망각(3막 구성, 마지막 막은 8턴 시간 제한)

## 연출
- **SVG 인물**: 승객 10명과 잔향체 12체는 개별 디자인, 일반·정예 적은 조합형 생성기(인간형·짐승·사물·덩어리·유령)로 그립니다. 외부 이미지 없이 모두 코드로 그려집니다.
- **모션**: 대기 호흡과 소품 흔들림, 공격할 때 인물이 대상 앞으로 뛰어드는 돌진, 합에서 두 인물이 가운데서 부딪히는 연출, 피격 반동, 회피, 흐트러짐, 공황, 쓰러짐
- **이펙트**: 참격 호·관통 섬광·타격 충격파, 치명타 별빛, 합 불꽃, 출혈·화상·진동·파열·침잠·호흡 입자, 방어막, 진동 폭발, 흐트러짐 파편, 화면 흔들림, 각인 컷인과 잔향체 전체 공격 경고
- **미리보기**: 승객 탭에서 기술·각인·피격·흐트러짐·상태 효과를 허수아비에 직접 재생해 볼 수 있고, 기록 탭의 잔향 도감에서 만난 적을 모두 볼 수 있습니다.

## 콘텐츠와 플레이 시간 (설계 목표 약 100시간)
- 이야기 12장 × 6 스테이지 (자동 진행 시뮬레이션 기준 약 170전투)
- 악몽 노선 12장 (레벨 +6, 잔향체 기믹 강화)
- 잔향 미궁: 5층 로그라이트, 심도 1~15, 유물 45종 + 세트 효과, 사건 14종
- 성장: 레벨 60(돌파 4단계), 기술 숙련 1~5, 돌파 특성, 각인 해방, 업적 36개

## 개발
소스는 `src/`에 나뉘어 있고 `node tools/build.js`가 하나의 `index.html`로 묶습니다.

```
src/core.js     상수·유틸
src/engine.js   전투 엔진 (합·코인·정신력·흐트러짐·상태·훅)
src/chars.js    승객 10종
src/enemies.js  적·정예·잔향체
src/world.js    이야기·유물·미궁 사건·업적
src/game.js     저장·성장·보상·미궁 진행
src/art.js      SVG 인물 아트
src/fx.js       캔버스 이펙트 · 컷인
src/ui.js       화면
tools/          빌드와 밸런스 시뮬레이션 (campaign.js, labsim.js, nmsim.js 등)
```
