# 참고: 수익창출 목적 1도 없고 되지도 않고 그냥 내가 심심해서 AI 딸깍으로 만든거임
# 잔향선 (ECHO LINE)

브라우저에서 바로 실행되는 **일대일 턴제 RPG**입니다. `index.html` 파일 하나만 열면 됩니다(설치·서버 불필요, 진행은 브라우저에 자동 저장).

직업 하나를 골라 **팀원 없이 끝까지 혼자** 싸웁니다. 림버스 컴퍼니에서는 전투 방식이 아니라 **기믹 설계 방식**(잠재 상태의 위력·횟수, 흐트러짐, 정신력, 보스마다 다른 규칙)을 참고했습니다.

## 전투 규칙
- **차례**: 내 차례에 기술 하나를 쓰거나 「집중」(에너지 +3·회복·정신력 +10)을 한다. 소모품은 차례를 쓰지 않는다.
- **에너지**: 턴마다 +2, 기본 공격 +1. 기술마다 비용과 재사용 대기 시간이 있다.
- **방어 입력**: 적이 공격할 때 막대가 지나가는 순간 누르면 방어(피해 −50%), 가운데 노란 칸이면 완벽 방어(피해 0, 직업 효과 발동). 설정에서 자동으로 바꿀 수 있다. 붉은 「방어 불가」 공격은 막을 수 없다.
- **적의 의도**: 적이 다음에 할 행동(이름·예상 피해·방어 불가·준비 턴)이 미리 보인다.
- **흐트러짐**: 적에게 피해(특히 타격)를 주면 게이지가 찬다. 가득 차면 적은 다음 행동을 잃고(준비하던 대기술도 취소) 받는 피해 +50%.
- **정신력**(−45~45): 높으면 피해·치명타가 오르고, −45가 되면 공황(한 턴을 제멋대로 움직인다).
- **잠재 상태**(위력·횟수): 출혈(행동할 때) · 화상(턴 끝) · 진동(폭발 시 흐트러짐) · 파열(피격마다) · 침잠(피격마다 정신력/피해) · 호흡(치명타) · 충전.
- **부위**: 일부 적은 부위(고기 걸이, 배수구, 거인의 팔, 자물쇠, 두 개의 달…)를 따로 노려 부술 수 있다.
- **레벨 차이**: 적이 나보다 높으면 더 아프게 때리고 덜 아프게 맞는다. 권장 레벨이 의미가 있다.

## 직업 10종 (각자 고유 기믹)
| 직업 | 기믹 |
| --- | --- |
| 혈검사 | 체력을 바쳐 「혈조」를 쌓고, 10이면 쓰러지지 않는 흡혈 상태 「불괴」 |
| 잿불 사제 | 「열기」 관리 — 100 이상 과열(강해지지만 스스로 탄다), 150 폭주, 열기를 재(보호막)로 |
| 종지기 | 저→중→고 음을 순서대로 이으면 「대종」, 진동 폭발로 흐트러짐 |
| 결투사 | 완벽 방어 시 자동 「응수」, 「기세」를 쌓아 확정 치명 「일섬」 |
| 수호기사 | 맞은 만큼 「인내」를 쌓아 「응징」, 쓰러지지 않는 「맹세」 |
| 도박사 | 동전 앞뒷면, 뒷면이 「행운」으로 쌓여 7이면 「잭팟」 |
| 심해 시인 | 정신력을 스스로 깎아 강해지고, −45에서 공황 대신 「심연」 |
| 포격수 | 「탄약」과 장전, 「충전」을 모아 쏟는 과충전 포격 |
| 인형술사 | 인형 「마리」가 피해를 나눠 받고, 「실」 4개로 적의 공격을 적에게 되돌린다 |
| 시계공 | 적의 두 수 앞을 보고, 「태엽」으로 체력 되감기·시간 정지 |

레벨 10·25·40에 특성(갈래 둘 중 하나)을 고르고, 기억 결정으로 기술 단계를 올린다(최대 5단계).

## 잔향체(보스) 12종
시계탑 수위(자정 카운트다운) · 굶주린 정육업자(고기 걸이 회복) · 침수 도서관 사서(수위·배수구·금서 봉인) · 디바(독무대·조명 낙하·앙코르) · 가면(가면마다 약점·내성, 가면 파괴) · 유령열차(가속·제동·탈선) · 웃는 얼굴(웃음 누적·풍선·정신력 공격) · 거인(석화 피부·양팔 파괴) · 재봉사(바늘땀 피해 공유·운명 고정) · 쌍둥이 달(교대·부활 카운트다운) · 거울 속의 차장(내가 쓴 기술을 그대로 되돌림) · 망각(3막, 기술 망각·두 번 행동·9턴 제한)

정예 12종도 각자 작은 기믹(벌금, 냉기 갑옷, 대사 지시, 다이너마이트, 자물쇠 …)을 가진다.

## 연출
- **로우폴리 벡터 인물**: 모든 인물·적·배경을 코드로 그린 다각형으로 표현한다. 큰 면은 빛 방향에 따라 잘게 나눠 명암을 주고, 빛을 받는 모서리에 림 라이트를 긋는다. 외부 이미지 없음.
- **관절 리그 애니메이션**: 팔·다리·무기 한 마디 뼈대에 키프레임 동작(돌진·베기·찌르기·내려찍기·시전·사격·방어·응수·피격·흐트러짐·쓰러짐·승리)과 대기 호흡. 애니풍(초당 24장)과 부드럽게(60) 중 고를 수 있다.
- **이펙트**: 가산 혼합 로우폴리 입자, 마법진·기둥·빔·투사체 곡선 비행·지면 균열·가시 솟음·충격파. 직업 기술 60개와 잔향체 대기술마다 전용 연출, 각성기 컷인, 화면 흔들림·섬광, 흐트러짐·격파 연출.
- **무대**: 장마다 다른 로우폴리 배경 14종(비 내리는 승강장, 정육시장, 물에 잠긴 서고, 불타는 극장 …).

## 콘텐츠와 플레이 시간 (설계 목표 약 100시간)
- 이야기 12장 × 6스테이지(단독·연전·정예·삼연전·잔향체), 승객 열 명의 이야기
- **악몽 노선**: 12장을 끝내면 열린다. 적 레벨 +12, 보스 기믹 강화
- **끝없는 미궁**: 층마다 길을 고르는 로그라이트. 유물 45종, 사건 14종, 5층마다 잔향체, 15층 이후 무한
- 장비(무기·방어구·장신구, 4등급, 부가 효과, +10 강화), 잔향체 유품 12종, 소모품, 업적 36개, 잔향 도감 60종
- 저장 슬롯 3개(직업별 여정), 자동 전투, claude.ai 안에서는 계정에 자동 저장

## 개발
```
node tools/build.js          # src/* → index.html, dist/artifact.html
node tools/sim.js 12         # 직업 × 보스 자동 전투 승률
node tools/campaign.js       # 실제 진행 규칙으로 이야기 전체 자동 진행
node tools/labsim.js poet 30 # 미궁 자동 진행
node tools/smoke.js out/     # 실제 화면 연기 시험 (Playwright)
node tools/rgallery.js heroes out.png   # 인물 갤러리
```
`src/`: `core`(상수) · `rig`(로우폴리 렌더러·인간형 리그·동작) · `rig_foes`(적 60종 외형) · `stage`(무대 배경·루프) · `data_cls`(직업) · `data_foes`(적·기믹) · `battle`(전투 엔진) · `world`(이야기·유물·장비·업적) · `game`(저장·성장·미궁) · `fx`(이펙트 엔진) · `fx_skills`(기술별 연출) · `ui_*`(화면)
