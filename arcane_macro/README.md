# Arcane Lineage 주먹 QTE 사냥 매크로

Roblox **Arcane Lineage**의 주먹(브롤러) 직업으로 **Party Table**을 쓰면서 사냥하는 이미지 인식 매크로입니다.
화면에 지정한 영역(박스)에서 지정한 이미지가 보이면, 그 이미지에 연결된 클릭/키 입력을 합니다.
QTE는 헬다이버즈 스트라타젬처럼 화면 아래 화살표 줄을 읽어 그대로 `W A S D`(또는 방향키)로 입력합니다.

```
전투 대기(사냥 이동) ──Attack 버튼 보임──▶ 에너지 읽기 ──▶ 로테이션에서 쓸 행동 결정
      ▲                                                       │
      │                                Attack 클릭 → Party Table 클릭(못 쓰면 Strike)
      │                                                       │
      └──── 적 턴 대기 ◀── QTE 화살표 입력 ◀── 적 버튼 클릭(가운데 적) ◀┘
```

> ⚠ Roblox 이용약관과 게임 규칙상 자동화 프로그램은 제재 대상이 될 수 있습니다. 사용 책임은 본인에게 있습니다.

## 설치와 실행 (Windows)

1. [python.org](https://www.python.org/downloads/)에서 Python 3.10 이상을 설치합니다(설치 화면에서 **Add python.exe to PATH** 체크).
2. 이 폴더의 `run.bat`을 더블클릭합니다. 필요한 패키지(numpy, opencv-python, mss)를 설치하고 창을 띄웁니다.
   - 직접 실행: `py -3 -m pip install -r requirements.txt` 후 `py -3 main.py`

Roblox는 **주 모니터**에 두고, 설정한 뒤에는 **게임 창 크기를 바꾸지 마세요**(바꾸면 영역·템플릿을 다시 잡거나 `크기 배율`을 넣어야 합니다).

## 사용 순서

### ① 영역 — 박스를 크기 조절해서 덮기
스킬 선택창·행동 선택창·적 선택창은 위치와 크기가 서로 다르므로, 각각을 박스로 따로 덮습니다.

| 영역 | 덮을 곳 |
| --- | --- |
| 행동 선택창 | 턴이 오면 오른쪽에 나오는 행동칸 전체 (Attack 버튼 포함) |
| 스킬 선택창 | Attack을 누르면 나오는 스킬 목록 전체 |
| 적 선택창 | 스킬을 고르면 나오는 적 이름 버튼 목록 전체 — **적이 가장 많을 때 기준으로 넉넉히** |
| QTE 화살표 | 화면 아래 화살표 줄 전체 — **화살표가 가장 많이 나올 때 기준으로 넉넉히** |
| 에너지 | 왼쪽 아래 에너지 표시만 딱 맞게 |
| 팝업(선택) | 전투 후 눌러서 닫아야 하는 창이 있다면 |

- `박스 열기/닫기`: 화면에 테두리 박스가 뜹니다. **위쪽 색 띠를 끌면 이동, 테두리·모서리를 끌면 크기 조절**.
  박스를 클릭한 뒤 방향키 = 1px 이동, Shift+방향키 = 1px 크기 조절(Ctrl을 같이 누르면 10px).
- `화면에서 드래그`: 화면을 얼려 놓고 드래그로 바로 지정합니다.

### ② 템플릿 — 버튼·화살표 잘라 두기
전투 중에 **F9**를 누르면 그 순간의 화면이 얼어붙고, 드래그할 때마다 어떤 템플릿인지 메뉴에서 고를 수 있습니다.
QTE 화살표처럼 금방 사라지는 것도 이렇게 자르면 됩니다. 오른쪽 위 확대경으로 픽셀 단위로 맞출 수 있습니다.

| 이름 | 필수 | 자를 것 |
| --- | --- | --- |
| `attack` | ✔ | 행동창의 Attack 버튼 |
| `skill_party_table` | ✔ | 스킬창의 Party Table 버튼 (**쿨타임이 아닐 때** 밝은 모습) |
| `skill_strike` | 권장 | 스킬창의 Strike 버튼 (Party Table을 못 쓸 때 대신 칠 공격) |
| `enemy_button` | ✔ | 적 선택 버튼 하나 — 이름은 아무 적이나 상관없음 |
| `arrow_up` | ✔ | QTE 위 화살표 하나 (나머지 3방향은 회전으로 자동 생성) |
| `arrow_down/left/right` | 선택 | 회전으로 만든 화살표 인식이 불안하면 직접 잘라 넣기 |
| `action_meditate`, `action_guard` | 선택 | 대체 행동으로 쓸 때 |
| `back` | 선택 | 스킬창 뒤로가기 (쓸 스킬이 없을 때 누름) |
| `energy_pip` | 선택 | 에너지 칸 하나 (pips 모드) |
| `popup_1~3` | 선택 | 전투 후 닫을 팝업 버튼 |

자를 때 요령: **버튼 안쪽만 딱 맞게**(뒤 배경이 들어가면 배경이 바뀔 때 인식이 떨어짐), 단색으로만 된 부분은 안 됩니다(어디서나 매칭되므로 저장을 거부합니다).

**에너지**: 전투 중 에너지가 0, 1, 2 … 일 때마다 `지금 에너지 수`를 맞추고 `에너지 영역을 이 값으로 저장`을 눌러 둡니다.
매 턴 지금 화면과 가장 닮은 상태를 골라 에너지 수로 씁니다(숫자 표시든 칸 표시든 상관없음).

### ③ 전투 설정
- **로테이션**: 위에서부터 *에너지 ≥ 코스트*, *쿨타임 지남*, *버튼이 밝게 보임*을 모두 만족하는 첫 행동을 씁니다.
  기본값: Party Table(에너지 2, 쿨 5) → Strike(에너지 0). 명상·가드는 켜면 대체 행동으로 씁니다.
- **QTE 입력 키**: WASD(기본) 또는 방향키.
- **고를 적**: `middle`(기본) — Party Table은 대상과 양옆을 치므로 가운데 적을 고르면 가장 많이 맞습니다.
- **사냥 이동**: 전투가 없을 때 `w:1.5, s:1.5`처럼 걸어 다니며 조우를 유도합니다(`a`, `d`, `space`, `wait:초`도 가능).

### ④ 인식 테스트
게임에서 해당 창을 띄워 둔 상태로 `지금 화면 인식 테스트`를 누르면 영역별로 무엇이 몇 점으로 보이는지 나옵니다.
`실시간 인식 보기`를 켜 두고 한 판 싸워 보면서 점수를 확인하세요. 점수가 임계값보다 **여유 있게** 높아야 안정적입니다.

### 실행
| 키 | 동작 |
| --- | --- |
| F6 | 시작 |
| F7 | 일시정지 / 재개 |
| F8 | 정지 |
| F9 | (정지 상태에서) 화면 얼리고 템플릿 자르기 |
| 마우스를 화면 **왼쪽 위 구석**으로 | 비상 정지 |

처음에는 `③ 전투 설정 → 드라이런`을 켜고 돌려서 로그만 확인해 보는 것을 권장합니다.

## 어떻게 인식하나

### 적 선택 버튼 — 이름이 매번 달라도 찾는 방법
버튼 전체를 비교하면 적 이름 글자 때문에 다른 적에서는 점수가 떨어집니다. 그래서 순서대로 시도합니다.
1. **왼쪽 끝 띠 매칭(기본)**: 캡처한 버튼에서 글자가 없는 왼쪽 끝(폭의 18%)만 잘라 비교 → 이름과 무관하게 모든 버튼을 찾음.
2. **색 덩어리**: 캡처한 버튼의 대표 색과 같은 색의 사각형 덩어리를 찾음(글자 구멍은 메움).
3. **고정 좌표(slots)**: `slots` 모드에서 적 선택창 기준 비율 좌표(`0.5,0.2; 0.5,0.5`)를 직접 지정.

찾은 버튼을 위→아래, 왼→오른 순으로 정렬한 뒤 `middle/first/last/index/random` 규칙으로 하나를 고릅니다.

### QTE 화살표
- 위 화살표 한 장을 90°씩 돌려 4방향 템플릿을 만들고, 영역 안의 모든 화살표를 찾은 뒤 겹친 후보는 점수 높은 것만 남깁니다.
- 줄이 여러 개면 위 줄부터, 줄 안에서는 왼쪽부터 읽습니다.
- 화살표가 나타나는 애니메이션 중에 읽지 않도록 **같은 배열이 연속 2번** 읽힐 때 입력합니다.
- 다 누른 뒤 노랗게 남아 있는 화살표를 **다시 누르지 않도록** 마지막 배열을 기억합니다(화면에서 사라지면 초기화).
- 다단 히트처럼 QTE가 여러 라운드로 나오면 전부 처리하고, 내 턴 흐름 밖에서 늦게 나타난 QTE도 감시합니다.

### 쿨타임 판별 (세 겹)
1. **밝기 비교**: 정규화 매칭은 어두워진 버튼도 높은 점수를 주므로, 찾은 버튼의 밝기·채도를 템플릿과 따로 비교해 어두우면 쿨타임으로 봅니다.
2. **턴 카운터**: 쓴 턴을 기억해 쿨타임 동안은 시도하지 않습니다.
3. **반응 검증**: 눌렀는데 적 선택창이 안 뜨고 스킬창이 그대로면 다음 후보(Strike)로 넘어갑니다.

## 문제 해결
- **클릭/키가 안 먹힘**: Roblox 창이 맨 앞에 있어야 합니다. 관리자 권한으로 실행된 게임이라면 이 프로그램도 관리자 권한으로 실행하세요.
- **화면 배율(125%, 150%)**: 프로그램이 DPI 인식 모드로 실행되므로 그대로 쓰면 됩니다. 배율을 바꿨다면 영역과 템플릿을 다시 잡으세요.
- **화살표 하나를 자꾸 못 읽음**: 화살표 임계값을 0.05 정도 낮추거나, 그 방향 화살표를 직접 잘라 넣으세요.
- **다른 화살표로 잘못 읽음**: 임계값을 올리고, 화살표를 더 딱 맞게 다시 자르세요.
- **방향키 모드에서 숫자패드가 눌림**: 확장키 플래그를 붙여 보내지만, 계속 문제면 WASD를 쓰세요.
- **Attack 버튼을 계속 다시 누름**: 행동 선택창 영역에 다른 버튼까지 들어가 있지 않은지, `attack` 템플릿이 딱 맞는지 확인하세요.
